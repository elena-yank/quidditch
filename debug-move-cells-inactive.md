# Debug Session: move-cells-inactive

## Symptom
- Иногда игрок не может совершить ход: ни одна клетка не активна для перемещения, хотя по этим клеткам не попадал бладжер и игрок ещё не совершал действий.
- Баг флапает: иногда проявляется, иногда нет.

## Expected
- В начале хода/после выбора игрока должны подсвечиваться допустимые клетки для перемещения (как минимум текущая или соседние по правилам), если игрок не оглушён/не заблокирован.

## Hypotheses
1. Состояние “активных клеток” не сбрасывается/не пересчитывается при смене текущего игрока или при начале нового хода.
2. Есть гонка событий: UI рисуется до того, как стейт (позиции/действия/оглушения) обновился, и подсветка вычисляется на устаревших данных.
3. В вычислении доступных клеток есть скрытое условие, которое иногда ложно (например, неверный флаг `hasActed`/`stunned`/`turnId`), из-за несинхрона между клиентом и сервером.
4. В редких случаях позиция игрока или координаты клетки становятся `null/undefined` или выходят за границы поля, и фильтр “валидных” клеток отбрасывает всё.
5. Подсветка зависит от порядка обхода/рандома (например, генерация/перемешивание) и при определённом порядке остаётся пусто из‑за ошибки.

## Evidence Plan
- Инструментировать (только логирование) места:
  - расчёт доступных клеток и причины исключения каждой клетки;
  - смену текущего игрока/начала хода;
  - флаги игрока (`hasActed`, `stunned`, `lastAction`, `turnId`) и его позицию;
  - события UI (клик по игроку/клетке) и итоговый список активных клеток.

## Notes
- Логи идут в NDJSON через debug-server, чтобы сравнить “плохой” и “хороший” прогоны.
